### Option 1: Comprehensive / Technical Focus (Recommended)

**Elite Face Anti-Spoofing Suite** | *Android Engineer*
*Kotlin, C++, Android NDK, Google ML Kit, CameraX, Coroutines, Gradle Kotlin DSL*
*   Architected a multi-modal biometric liveness detection Android application designed to prevent identity fraud via presentation attacks (printed photos, screen playbacks, deepfakes).
*   Integrated a high-performance Convolutional Neural Network (CNN) via the Android NDK (C++) to provide silent, sub-second passive liveness verification.
*   Engineered interactive challenge-response tests (Blink, Smile, Yaw/Head Turn) by piping AndroidX CameraX video streams into Google ML Kit Face Detection for real-time 3D geometry and facial expression tracking.
*   Modernized the legacy codebase to 2024 standards by migrating to a centralized Gradle Kotlin DSL version catalog, enforcing Java 17 compatibility, and refactoring background tasks to use lifecycle-aware Kotlin Coroutines.
*   Designed a premium, edge-to-edge Material Design dashboard acting as the central hub for the biometric verification modules.
